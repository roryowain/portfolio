The sample breakdown

What the free report actually looks like

Here's the one-page breakdown I send, worked through on one of the sites above — the plumbing & heating firm scoring 39/100.

Sample diagnosis: issue, what it means, the fix, and expected gain
Issue What it means The fix Expected gain
Multi-megabyte photos, scaled down in the browser The site sends a huge original photo and lets your phone squash it into a small box — you pay to download pixels you never see. Resize and compress images to the size they're actually shown at. Often halves load time on its own
15–30 plugins, each loading scripts on every page Every plugin adds its own file to download and run — even ones doing nothing on the page you're looking at. Remove what's unused; load the rest only where it's needed. Typically 1–3 s off
Render-blocking theme & page-builder CSS/JS The browser has to fully load the page-builder's styling code before it draws anything — visitors stare at a blank screen meanwhile. Strip it to the CSS actually used; load the rest after the page shows. Usually a second or more off first paint
No caching headers Every repeat visit re-downloads the whole site from scratch, as if it were the first time. Set the server to tell the browser what to keep. Return visits load close to instantly
Third-party embeds loading before the content Maps, review widgets, chat pop-ups and video sit in the queue ahead of your actual words and photos. Defer or lazy-load them so content shows first. Content typically appears 1–2 s sooner
