# API API — Demo Site

A single-page portfolio demo for a fictional modern-Malaysian wood-fire restaurant in Kuala Lumpur, built to showcase freelance web development work. It's a type-led, art-directed site with no external images — every visual is CSS gradients, inline SVG, and typography (Anton, Instrument Serif, Manrope) — centered on "The Fire Menu," a menu system that rates each dish by 1–4 inline SVG flames. Built with Tailwind CSS (Play CDN) and Alpine.js, no build step required.

To preview locally, just open `index.html` directly in a browser. To deploy on Netlify, drag the `restaurant` folder onto the Netlify dashboard (or run `netlify deploy` from inside it) — there's no build command or publish directory to configure, since `index.html` is already the site root.
