# Lakeline Dental Studio — Demo

A single-page portfolio demo for a fictional modern dental studio in Austin, Texas, built to show what a freelance client site can look like without relying on stock photography or a medical-template aesthetic. It leans on typography (Young Serif + Nunito Sans), a warm pine/sage/apricot palette, and hand-drawn inline SVG illustration for the hero, service glyphs, comfort-menu icons, and team avatars. The signature section is "Honest Pricing" — a full published price list, a rarity in US dentistry, presented as the centerpiece rather than buried in fine print. The page also includes a keyboard-accessible FAQ accordion (built with a CSS grid-template-rows collapse, no plugin) and a validated three-step Alpine.js booking form with no backend.

To view it locally, just open `index.html` in a browser — there's no build step, package manager, or server required; Tailwind and Alpine load from CDN. To deploy on Netlify, drag the `clinic-us` folder onto the Netlify dashboard (or run `netlify deploy` from inside it) and point the publish directory at the folder root; every asset is referenced with a relative path so it works unmodified from any static host, subpath, or custom domain.
